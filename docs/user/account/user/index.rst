User accounts
=============

.. TODO this is not helpful placeholder content for now. There is a number of

In order to create and maintain projects, you will first need a user account.
The easiest way to get started is by signing in using
your account with a provider like |git_providers_or|.
This will create a user on Read the Docs
and a :doc:`connected service <./connected-services>` linked to the provider account
that will allow you to use features like
automatic project creation, private repository support, and pull request builds.
